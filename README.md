# Car Insurance Claims Analysis — Tableau

## Project Overview
This project presents a data visualisation project created using Tableau, focused on car insurance claims and driver age distribution.

## Objective
To explore car insurance claims data through visualisation and make the information easier to interpret.

## Tool Used
- Tableau

## Dashboard
**View the interactive Tableau dashboard:**
[Open Interactive Tableau Dashboard](https://public.tableau.com/views/Car_Insurance_Claims_Tableau_01/DriverAgeDistribution) 

## Visualisation Focus
- Driver age distribution
- Exploration of car insurance claims data through Tableau

## Key Findings
Key findings will be documented after reviewing the dashboard and verifying the visualised results.

## Limitations
The findings depend on the underlying dataset and the visualisations available in the dashboard. They should not be interpreted as conclusions beyond what the data supports.
